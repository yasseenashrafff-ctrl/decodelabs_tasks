# Project 2 – Iris Flower Classification

## Description

This project uses Machine Learning to classify Iris flowers into different species using the Iris dataset.

## Algorithm

Decision Tree Classifier

## Dataset

The project uses the built-in Iris dataset from Scikit-learn.

* Samples: 150
* Features: 4
* Training samples: 120
* Testing samples: 30

## Results

The model achieved an accuracy of 100.0% on the test data.

## Technologies

* Python
* Scikit-learn
* Decision Tree
* Machine Learning

## How to Run

Install the required library:

```bash
pip install scikit-learn
```

Then run:

```bash
python classification.py
```
